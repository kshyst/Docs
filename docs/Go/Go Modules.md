# Go Modules: go.mod and go.sum

Go modules are the official dependency management system in Go. They are defined by two key files at the root of a project.

---

## go.mod
The `go.mod` file defines the module's import path and lists the direct and indirect dependencies the project requires, along with their specific versions.

* **Purpose**: Track project dependency requirements and the module path.
* **Format**: Human-readable.
* **Example**:
  ```go
  module github.com/username/myapp

  go 1.22

  require (
      github.com/google/uuid v1.6.0
      golang.org/x/crypto v0.21.0 // indirect
  )
  ```

---

## go.sum
The `go.sum` file lists the expected cryptographic hashes of the source code of specific dependency versions.

* **Purpose**: Security and integrity verification. It ensures that future builds download the exact same code and that dependencies haven't been modified or tampered with.
* **Format**: Autogenerated list of hashes (do not edit manually).
* **Example**:
  ```text
  github.com/google/uuid v1.6.0 h1:NIQLunv5pl15qf445VpTfv7wJ9j4p560879wz8Lgqf4=
  github.com/google/uuid v1.6.0/go.mod h1:TIyPZe1r84mJc8yy5SZVRAihm5k9fM7YqOa1YJpE=
  ```
